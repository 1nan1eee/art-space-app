# ArtSpace App

ArtSpace - это приложение для просмотра картин передвижников (российских художников второй половины 19 - начала 20 века). Пользователи могут просматривать различные картины, переключаться между ними и читать их описания.

## Описание

ArtSpace позволяет пользователям наслаждаться искусством, представляя коллекцию картин с возможностью навигации между ними. Приложение адаптируется к ориентации экрана, обеспечивая оптимальный пользовательский интерфейс как в портретном, так и в ландшафтном режимах.

## Технологии

- **Kotlin**
- **Jetpack Compose**

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/1nan1eee/art-apace-app.git
   ```
2. Откройте проект в Android Studio.
3. Убедитесь, что у вас установлены зависимости и SDK для Android.
4. Запустите приложение на эмуляторе или реальном устройстве.

## Использование

- При запуске приложения вы увидите первую картину в центре экрана.
- Используйте кнопки "Предыдущая" и "Следующая", чтобы переключаться между картинами.
- В портретном режиме картина отображается с описанием под ней, а в ландшафтном - с описанием сбоку.

## Структура проекта

- **MainActivity.kt**: Основной класс активности, который управляет UI и связывает его с ViewModel.
- **ArtworkViewModel.kt**: ViewModel, который управляет данными о произведениях искусства и их индексами.
- **Artwork.kt**: Модель данных для хранения информации о произведениях искусства.

## Примечания

- Убедитесь, что у вас есть все необходимые ресурсы изображений в папке `res/drawable`.
- Вы можете добавлять новые произведения искусства, изменяя массив в методе `loadArtworks()` в `ArtworkViewModel.kt`.
